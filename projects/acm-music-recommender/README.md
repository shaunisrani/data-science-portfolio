# ACM AI Team 3 – Summer 2025 Data Science Project

Resume-based music recommendation project developed as part of ACM AI Team 3 in Summer 2025.

## Overview
This project used a Kaggle resume dataset to build a music recommendation system that suggests songs based on the content of a user's resume. The model was trained, optimized, and embedded into a transformer-based pipeline, then deployed on the Hugging Face Spaces platform. The project was also presented at the Summer 2025 ACM Projects Showcase.

## What I did
- Trained and optimized a transformer-based recommendation model
- Embedded a Kaggle resume dataset for semantic matching
- Built a system that recommends the top 5 songs based on a user's resume
- Contributed to deployment on Hugging Face Spaces
- Presented the project at the Summer 2025 ACM showcase

## Tools
- Python
- Transformers
- Google Colab
- Hugging Face Spaces
- Kaggle dataset
